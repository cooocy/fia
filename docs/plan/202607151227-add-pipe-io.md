# Fia standard input/output pipe support

## Summary

Make Fia follow Unix pipe conventions: `fia w` can consume redirected stdin,
and `fia cat` writes only the exact note content to stdout.

## Implementation changes

- Resolve write content in this order: explicit `-c/--content`, non-TTY
  stdin, then the system clipboard for interactive use.
- Preserve stdin exactly, including trailing newlines and indentation. Treat an
  explicitly selected but empty source as an error instead of falling through
  to another source.
- Write the default `cat` result with `sys.stdout.write()` so it gains no extra
  newline or formatting.
- Send missing-note and invalid-content errors to stderr and exit nonzero, so
  pipelines never consume diagnostics as note content.
- Keep clipboard output, aliases, and tags compatible, and document pipe usage
  in both READMEs.

## Test plan

- Cover explicit content precedence, piped multiline input, clipboard fallback,
  and empty piped input.
- Cover exact stdout output with and without trailing newlines.
- Cover missing-note stderr and nonzero exit behavior.
- Run the existing and new unit tests.

## Assumptions

- Python's configured text stream encoding is used for stdin and stdout.
- `ls`, `rm`, and `clean` pipe behavior is out of scope.
- Create-success messages remain unchanged; only default `cat` stdout is
  guaranteed to contain pure note content.
